# JoyDSH 用户操作与按键指南

JoyDSH 是一个**手柄优先（Gamepad-First）、键盘友好**的本地智能体开发工作空间。它将开发流程以任务为中心组织，让开发者在舒适靠背、站立或沙发姿态下，显著减少对鼠标的依赖。

---

## 🎮 控制器与按键对照表

JoyDSH 支持标准 **DualSense (PlayStation)**、**Xbox / XInput** 兼容手柄以及**键盘 / 鼠标**作为完整备用输入。

| 语义动作 | DualSense (PS) | Xbox / 标准手柄 | 键盘映射 | 功能说明 |
| :--- | :---: | :---: | :---: | :--- |
| **确认 / 选择** | ✕ (南侧键) | **A** (南侧键) | `Enter` / `Space` | 进入工作空间、确认选项、执行常规操作 |
| **返回 / 关闭** | ◯ (东侧键) | **B** (东侧键) | `Escape` | 退出输入框、关闭临时弹窗/命令中心、返回上一层 |
| **主要操作 (接受)** | ▢ (西侧键) | **X** (西侧键) | `A` (非编辑时) | 成果评审时快速**接受当前文件变更** |
| **更多操作 (拒绝)** | △ (北侧键) | **Y** (北侧键) | `R` (非编辑时) | 成果评审时进入**拒绝确认对话框** |
| **精确焦点移动** | 十字键 (D-Pad) | 十字键 (D-Pad) | 方向键 `↑` `↓` `←` `→` | 在相邻焦点卡片与按钮之间精确移动 |
| **快速连续移动** | 左摇杆 | 左摇杆 | 方向键长按 | 快速在长列表中连发滚动 |
| **长内容滚动** | 右摇杆 | 右摇杆 | `PageUp` / `PageDown` | 纵向滚动执行流日志、差异比对和长文档 |
| **切换焦点区域** | **L1 / R1** (肩键) | **LB / RB** (肩键) | `Tab` / `Shift+Tab` | 在侧边栏、主工作区、检查器之间快速跳跃 |
| **切换内容页面** | **L2 / R2** (扳机) | **LT / RT** (扳机) | `[` / `]` | 在任务检查器的【动态】【变更】【成果】页面间切换 |
| **命令中心** | 菜单键 (Options) | 菜单键 (Menu) | `Cmd/Ctrl + K` | 唤起/关闭全局命令中心（不中断前台任务） |
| **立即暂停** | 长按菜单键 | 长按菜单键 | `Cmd/Ctrl + .` | 紧急中断当前前台智能体的执行 |
| **语音输入** | **创建/分享键 (Select/Share)** | **视图/返回键 (View/Back)** | `Cmd/Ctrl + Shift + V` / `F5` | 自动聚焦任务输入框并模拟触发 **Spokenly / 系统听写** |

> [!TIP]
> **文字与语音输入**：
> - **实体键盘**：长文本、代码提示词与 Git 提交说明直接使用实体键盘输入。输入框聚焦时，方向键自动保留给文字光标编辑；按 `Escape` 或手柄东侧键可退出编辑模式并保持稳定焦点。
> - **语音输入 (Spokenly / Superwhisper / 系统听写)**：手柄按下 **Select / View 键**（或键盘 `Cmd+Shift+V` / 点击输入框麦克风按钮），JoyDSH 会自动将焦点切入任务输入框并在系统底层模拟目标按键（默认 **Right Command (右侧 Cmd)**，可在设置中切换为 Right Option、Fn、F5 等），无需放下手柄即可畅快语音输入。支持**单击切换（Toggle）**与**按住说话（Push-to-Talk）**两种模式。

## 🚀 核心任务闭环操作流程

### 1. 工作空间与项目中心
- **启动进入**：启动 JoyDSH 后，首先显示项目中心（Project Center）。
- **新建项目**：手柄聚焦至输入框，键盘输入文件夹名称，按确认键即可自动创建并在该目录下启动新任务。
- **打开已有项目**：选择“打开文件夹”，系统目录选择器将帮助快速定位已有代码仓库。
- **权限预设**：可为项目设置默认权限模式：
  - **标准权限（默认）**：以当前工作空间为沙箱边界，敏感/破坏性命令需要人工审批；
  - **完全访问（Full Access）**：智能体继承当前用户系统权限，适合受信任的高吞吐自动化开发。

---

### 2. 任务执行与结构化计划
- **输入任务目标**：在前台任务下方输入框键入开发目标并发送。
- **实时执行流**：执行流实时反映智能体的思考、工具调用与终端输出；使用**右摇杆**可随时平滑回滚查看历史。
- **结构化计划**：右侧检查器实时投影智能体的执行步骤（如 `3/5` 步骤），展示当前步骤、涉及文件与完成进度。

---

### 3. 处理权限审批
- 当智能体执行涉及工作区外读写、依赖安装或高风险命令时，会触发**审批卡片**；
- 审批卡片清晰展示命令名称、完整参数、影响范围与风险等级；
- 使用手柄南侧键允许一次，或东侧键拒绝并附带拒绝理由；
- 高风险破坏性操作需长按确认，防止误触。

---

### 4. 成果检查、安全拒绝与回滚
- **成果三页视图**：任务暂停或完成后，按左右扳机（`L2/R2`）在检查器中切换：
  - **动态**：查看当前步骤与执行概览；
  - **变更**：查看任务产生的文件清单、行级文本差异（Diff Hunks）与二进制状态；
  - **成果**：聚合展示已接受/待评审状态。
- **逐文件评审**：
  - 手柄移动到指定文件变更项，按**西侧键**一键标记为【已接受】；
  - 按**北侧键**触发【拒绝变更】，将弹出确认弹窗并精准恢复该文件至任务开始前的基线状态。
- **任务级安全回滚**：
  - 若需丢弃整个任务产生的所有文件修改，按菜单键打开命令中心，选择【回滚任务变更】。
  - JoyDSH 采用原子恢复快照机制，**严禁使用 `git clean` 或 `git reset --hard`**，确保安全无副作用。

---

### 5. 智能体生成提交说明与精准提交
- 当所有需要保留的变更均已标记为【已接受】后，在命令中心或检查器中触发【智能体提交】；
- 智能体基于当前快照的已接受变更自动生成规范的 Git Commit Message；
- 开发者可在弹出的确认卡片中直接编辑提交说明；
- 确认后，Commit Bridge 将**仅提交已接受的文件变更**，未接受的草稿文件仍妥善保留在工作区中。

---

## 🛠️ 故障排查与运行控制

- **DSH 智能体运行时**：桌面端自动受管启动位于本地 `127.0.0.1:43127` 的 DeepSeek Harness 运行时。可在命令中心或界面顶部实时查看连接与运行时健康状态。
- **多设备无缝切换**：键盘、鼠标与手柄输入随时可交替使用，不会导致焦点丢失或重置。
