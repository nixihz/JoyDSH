# 将手柄界面与智能体运行时分离

JoyDSH 将作为独立的 Tauri 桌面应用，把 DeepSeek Harness 视为可替换的智能体运行时。JoyDSH 通过 DSH 插件、组合包、智能体控制和会话事件完成集成，不复刻或派生官方网页界面。这样既能保留专门设计的手柄交互模型，也能隔离 DSH 在开发者预览阶段发生破坏性变更的风险。

## 考虑过的方案

派生官方网页界面虽然可以加快最初原型的开发，但会让 JoyDSH 的导航和视觉架构与上游实现细节紧密耦合。只构建 DSH 界面插件可以减少打包工作，却会限制产品外壳和输入模型。

## 后续影响

JoyDSH 独立拥有自己的呈现层和手柄状态机。DSH 集成必须位于带版本的适配层之后，每个受支持的 DSH 版本都需要明确的兼容性测试。
