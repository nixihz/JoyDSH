# 分诊标签

工程技能使用五种固定的分诊角色。本文件记录这些角色在当前问题跟踪器中的实际标签。

| 技能中的角色 | 当前项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给智能体执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到某个分诊角色时，使用表格中对应的当前项目标签。
