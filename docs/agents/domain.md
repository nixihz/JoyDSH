# 领域文档

工程技能探索代码前应按以下规则读取和使用本仓库的领域文档。

## 探索前读取

- 阅读根目录 `CONTEXT.md`
- 阅读 `docs/adr/` 中与当前工作相关的架构决策
- 文件不存在时直接继续，不要因为缺失而阻塞工作

## 文件布局

本仓库采用单语境布局：

```text
/
├── CONTEXT.md
├── docs/
│   └── adr/
└── src/
```

## 使用统一语言

问题标题、重构方案、假设和测试名称应使用 `CONTEXT.md` 定义的领域术语，不得改用其中明确要求避免的同义词。

需要的概念不在领域语境中时，应先判断是否误用了项目语言；若确实存在领域缺口，再通过领域建模流程补充。

## 处理架构决策冲突

产出与现有 ADR 冲突时，必须明确指出冲突，不得静默覆盖已有决定。
