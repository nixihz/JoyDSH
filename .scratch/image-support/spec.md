# JoyDSH 图片支持规格

## 目标

为 JoyDSH 提供全链路的多模态图片支持，使用户能够通过剪贴板粘贴、拖拽或截图向任务会话发送图片，并在会话气泡、Markdown 输出与全屏原图灯箱（Lightbox）中查看与交互。

## 行为规范

1. **多模态输入与发送**：
   - 支持格式：`image/png`、`image/jpeg`、`image/webp`、`image/gif`。
   - 剪贴板粘贴：在输入框或窗口内按 `Cmd+V` / `Ctrl+V` 可直接提取图片并加入待发送附件栏。
   - 拖拽放置：支持将图片拖入窗口，显示全视口拖拽遮罩，松开后加入待发送附件。
   - 截图：从输入工具栏截取当前 JoyDSH 项目页面，完成后直接加入待发送附件栏。
   - 待发送附件栏（AttachmentRail）：在输入栏上方展示 64px 缩略图横排，每张卡片提供删除按钮和点击原图预览。
   - 支持单独发送图片或图文混合发送。

2. **DSH 协议与持久化通信**：
   - `session.prompt`：组装 `content: [{ type: 'text', text }, { type: 'image', mediaType, data, name }]`。
   - `session.attachment`：按需拉取历史会话中的持久化图片数据。

3. **会话历史与图片渲染**：
   - 任务投影正确解析 `user/message` 和 `assistant/message` 中的图片块。
   - 单图展示：最大长边 240px，宽高比限制在 [0.25, 4]，超出部分居中或自适应裁切。
   - 多图展示：瓦片网格（Tile Gallery）。
   - Markdown 中的 `![alt](url)` 图片渲染支持，具备加载态和错误回退。

4. **全屏原图灯箱（ImageLightbox）**：
   - 点击任何图片（待发送预览、消息内图片、Markdown 图片）唤起灯箱。
   - 黑色半透明背景模糊（`backdrop-filter`）。
   - 按 `Escape`、手柄东键（◯ / B）、点击遮罩或右上角关闭按钮退出并恢复焦点。

5. **手柄空间导航**：
   - 焦点图涵盖截图与粘贴按钮、待发送项删除与灯箱交互。

6. **当前页面截图（Current Page Screenshot）**：
   - 支持通过 PS5 手柄按键 / 快捷键（`PrintScreen`、`F7`、`Cmd+Shift+S`、`Cmd+Shift+X`）与工具栏“截图”按钮触发屏幕捕获。
   - 截取当前 JoyDSH 项目窗口的整体可见页面，不捕获整个桌面，也不打开额外的标注页面。
   - 截图完成后自动写入系统剪贴板并追加至当前输入栏待发送附件列表，聚焦输入框以便直接发送。
   - 工具栏支持“粘贴”按钮与全局快捷粘贴（`Cmd+V`）。
