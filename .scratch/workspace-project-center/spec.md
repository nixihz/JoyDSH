# 工作空间项目中心

Status: resolved
Label: ready-for-agent

## 目标

让用户先设置一个默认工作区根目录，之后可以通过项目名直接创建文件夹，或使用系统目录选择器打开任意已有文件夹。

## 范围

- 在应用数据目录持久化默认工作区根目录和最近项目。
- 项目创建只允许根目录下的单层名称，禁止路径穿越。
- 项目中心使用可聚焦列表展示根目录直属项目与最近项目。
- 创建或选择项目后，优先恢复该工作空间已有任务，否则创建任务会话。
- 项目中心从命令中心进入，不在顶栏增加按钮。

## 验收标准

1. 工作区根目录在应用重启后保留。
2. 输入项目名可在根目录下创建真实文件夹并立即打开。
3. 用户可使用系统目录选择器设置根目录或打开任意文件夹。
4. 最近项目和根目录直属子目录合并去重，最近使用项优先。
5. 项目列表支持方向、确认和返回语义，760x600 下无水平溢出。

## Answer

已完成工作空间项目中心。Tauri 目录服务持久化默认根目录和最近项目，支持安全创建单层项目文件夹、打开任意文件夹和项目列表合并去重。主界面不再要求手填绝对路径，命令中心可直接进入项目选择；真实交互已验证焦点进入、返回恢复和 1280x720 / 760x600 布局。
