# 控制器外设容错与焦点韧性

Type: task
Status: resolved

## Scope

测试手柄断连、重新连接、系统睡眠唤醒、窗口失焦切换时的焦点保持与恢复，确保无焦点丢失与漂移。

## Answer

已全面优化手柄与键盘在输入框中的焦点行为：
1. 手柄在输入框与文本域中不再被阻断，摇杆与十字键可全向自由移动并平滑切出输入区域；
2. 键盘在单行输入框中支持上下方向键切出，多行文本域支持首尾边界逃逸与 `Tab`/`Shift+Tab` 区域切换；
3. 文本输入框中支持通过手柄确认键提交表单，或键盘 `Cmd/Ctrl+Enter` 快捷发送；
4. 项目中心焦点图重构为标准的 2D 网格空间连接，上下左右移动完全符合视觉直觉。
