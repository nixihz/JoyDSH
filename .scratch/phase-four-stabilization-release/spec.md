# 阶段四：稳定化与发布准备

## 目标

完成 JoyDSH 桌面应用的跨平台打包（macOS / Windows）、外设容错与焦点稳定性验证、长会话性能压测以及用户操作指南沉淀，达到 MVP 正式交付标准。

## 范围

1. **桌面安装包打包与分发**：
   - 配置 Tauri 2 打包配置（`bundle` 激活，应用图标、macOS bundle/dmg、Windows msi/nsis）；
   - 在 `package.json` 中提供标准打包命令 `pnpm build:app`；
   - 固化 DeepSeek Harness（`0.1.1-rc.2`）受管运行时集成与分发说明。
2. **外设容错与焦点韧性实测**：
   - 验证 DualSense / Xbox 手柄热插拔、断连与重连时的焦点状态持久化；
   - 验证系统睡眠唤醒、应用窗口失焦切出/切回时的焦点图无跳动与死锁；
   - 验证全键盘/鼠标完整备用输入的无缝切换。
3. **长会话与高负载性能压测**：
   - 验证上千条流式事件、上百个文件变更下 Task Inspector 的滚动与渲染稳定性；
   - 确保按键交互到界面视觉反馈延迟在 100ms 以内。
4. **用户指南与按键说明**：
   - 编写手柄语义操作与键盘快捷键对照表；
   - 完善使用说明与核心任务闭环引导。

## 验收条件

- 全仓 TypeScript、Vitest、Rust 单元与集成测试、打包构建全量通过；
- 能够通过 `pnpm build:app`（或 `tauri build`）在当前系统构建原生桌面可执行包；
- 核心闭环满足无鼠标操作与 100ms 响应延迟标准。
