# 阶段二：任务状态与计划

## 目标

让 TV 任务页准确呈现 DSH 的真实执行结果，并在运行时产生结构化 Todo 时直接显示计划，不增加顶栏入口或模式按钮。

## 范围

- 根据 `turn/start` 与 `turn/end.reason.kind` 投影执行中、完成、取消、受阻、中断、输出截断和失败状态。
- 根据 `todo/write` 的全量快照投影当前计划。
- 任务页有计划时自动呈现计划进度与条目；无计划时保持当前输出布局。
- 继续保留停止任务能力；本阶段不实现审批、文件差异或 Git 操作。

## 验收

- 历史恢复和实时事件使用同一套投影逻辑。
- 新一轮开始时清除上一轮失败，但保留最近计划，直到新的 `todo/write` 替换。
- 取消、受阻、输出截断和运行时中断不显示为“等待输入”。
- 计划条目只来自结构化 `todo/write`，不从模型文本猜测。
- 桌面与窄窗口无横向溢出，TV 焦点路径不增加无意义按钮。
