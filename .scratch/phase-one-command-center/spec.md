# 阶段一：命令中心纵向切片

Status: resolved
Label: ready-for-agent

## 目标

为 TV 版本提供一个不占用顶栏按钮的全局命令入口，使用手柄菜单键或 `Cmd/Ctrl+K` 打开。

## 范围

- 命令中心以底部覆盖层呈现，不在顶栏增加入口。
- 首版只承载返回当前任务、停止当前任务和打开模型设置。
- 使用方向、确认和返回语义操作，关闭后恢复打开前焦点。
- 设置页打开时不叠加命令中心。

## 验收标准

1. `Cmd/Ctrl+K` 在普通元素或文字输入框聚焦时都能打开命令中心。
2. 手柄菜单键与键盘产生同一语义动作。
3. 命令列表可使用方向键和确认键操作。
4. `Escape`/手柄返回或背景点击会关闭覆盖层并恢复原焦点。
5. 760x600 与 1280x720 视口下无水平溢出和内容遮挡。

## Answer

命令中心已完成，并新增项目中心入口。`Cmd/Ctrl+K` 与手柄菜单键共用语义动作，底部面板支持方向导航、确认、返回和原焦点恢复。
