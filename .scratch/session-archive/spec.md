# 任务会话归档

## 目标

允许用户从当前工作空间隐藏已完成的任务会话，并可在之后恢复。归档不删除 DSH Host 的会话日志或关联数据。

## 行为

- 命令中心提供“归档当前任务”。
- 运行中或等待审批的任务不可归档，用户需先暂停。
- 归档当前任务后，JoyDSH 自动选择同项目中下一条可见任务；没有其他任务时显示项目空状态。
- 命令中心提供“已归档任务”视图，按归档时间倒序排列。
- 恢复后任务回到原工作空间并成为前台任务。
- DSH `session.list` 仍是任务会话事实来源；JoyDSH 仅持久化归档任务 ID 和归档时间。

## 持久化

使用版本化浏览器存储键 `joydsh.task-archives.v1`：

```json
{
  "version": 1,
  "entries": [
    { "taskId": "session-id", "archivedAt": 1735689600000 }
  ]
}
```

损坏条目、重复 ID 和未知版本会被安全忽略。归档记录对应的 DSH 会话不存在时不展示，但保留记录，以便会话在后续重连中重新出现。

## 非目标

- 不调用或模拟 DSH session 删除。
- 不删除日志、附件、fork lineage、子智能体或工作空间数据。
- 当前版本不提供批量归档或自动归档。
