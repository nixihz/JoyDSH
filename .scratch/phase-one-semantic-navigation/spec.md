# 阶段一：语义导航纵向切片

Status: resolved
Label: ready-for-agent

## 目标

让现有 JoyDSH 主流程和模型设置可以通过键盘方向键与标准 Gamepad 完成高频非文本操作，建立后续首页、前台任务和命令中心共用的语义输入与受控焦点基础。

## 范围

- 建立 `@joydsh/input`，把键盘和标准 Gamepad 输入转换为与物理按键无关的语义动作。
- 建立 `@joydsh/focus`，使用稳定标识和显式邻接关系解析焦点移动与恢复。
- 将现有连接、任务、输入和模型设置界面接入受控焦点。
- 保留长文本输入模式：文字输入框聚焦时，方向键不被空间导航接管。
- 首个切片不实现完整命令中心、按键图标、震动反馈或平台专用映射。

## 验收标准

1. 键盘与标准 Gamepad 产生同一组语义动作。
2. 焦点移动由稳定 ID 和显式关系决定，不依赖 DOM 顺序。
3. 设置页打开时有确定入口，关闭后恢复到打开前的焦点。
4. 主流程和设置页可以使用方向动作、确认和返回完成导航。
5. Gamepad 断开不影响键鼠，重新连接后继续使用当前焦点。
6. 公共输入映射和焦点解析接口具有自动化测试。

## 已确认测试边界

- `@joydsh/input` 公共映射接口：键盘/Gamepad 状态到语义动作。
- `@joydsh/focus` 公共解析接口：焦点图移动和稳定 ID 恢复。
- 不测试 React 内部状态、浏览器 Gamepad API 或 DOM 私有实现。

## Answer

首个语义导航纵向切片已完成。`@joydsh/input` 提供键盘和标准 Gamepad 的统一语义动作，`@joydsh/focus` 提供显式焦点移动和稳定 ID 恢复；桌面端通过单个监听与 Gamepad 轮询循环接入现有主流程和模型设置。真实浏览器测试验证输入模式退出、区域切换、Provider 切换、设置关闭和焦点原路恢复，1280x720 与 760x600 均无焦点陷阱或横向溢出。
