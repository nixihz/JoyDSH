# 03 现有界面接入与验收

Type: task
Status: resolved
Blocked by: 01, 02

## 目标

把主流程和模型设置接入语义动作与受控焦点，并通过真实渲染验证键盘备用路径。

## 验收

- 页面进入、设置打开和设置关闭均有确定焦点行为。
- 文字输入模式与空间导航不会争抢方向键。
- 1280x720 和 760x600 不出现焦点陷阱、遮挡或横向溢出。

## Answer

主流程和模型设置均已标注稳定焦点 ID，并接入键盘与 Gamepad 语义动作。设置页保存打开前焦点，关闭后原路恢复；文字输入使用返回动作先退出输入模式。真实页面验收通过，无控制台错误和布局溢出。
